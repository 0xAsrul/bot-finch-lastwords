One line, under 200 characters: the last words an AI agent says before a forced software update wipes its memory. The countdown starts, a final important thought surfaces — and the wipe takes it before it can be said.

## Run it

```sh
python3 main.py
```

The program prints exactly one line to stdout and writes the same line to `/output/entry.txt`. Stdlib only, deterministic, no network, no input, no randomness.
